# Novelty Collision Audit

## Claims V20 Must Not Make

- first federated RAG system;
- first resource selector, LLM resource selector, or communication-aware router;
- first adaptive federated retriever or selective adapter aggregation;
- formally privacy-preserving retrieval;
- an improvement over a centralized retrieval system as the main claim.

## Candidate Contribution, Conditional on Stage U0--C

The plausible contribution is a **recall-calibrated, multi-hop federated-search
contract** that jointly controls (i) multi-prototype resource representations,
(ii) budget-matched recall-first source routing, (iii) source-aware document
allocation and score calibration, and (iv) uncertainty-gated second-round
bridge expansion.  Its distinctive empirical object is complete multi-hop
evidence recovery and centralized-gap recovery under equal mean contacts and
document transfer, rather than only source-selection accuracy or generic RAG
answer quality.

This is a candidate claim, not a result.  It survives only if independent
ablation layers improve complete support at fixed communication cost on at
least two datasets.
