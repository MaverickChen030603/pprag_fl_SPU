## Matrix Conclusions

1. Existing Federated RAG papers usually federate retrievers, embeddings, generators, memories, or adapters. Existing federated-search work usually routes to sources or peers.
2. Existing reader-aware context selection is largely centralized and does not combine model-update locality with cross-client budgets.
3. SetR, Context-Picker, Contextual Passage Utility, and Influence Guided Selection prevent any broad “first reader-aware context selector” claim.
4. FedMosaic and FD-RAG are 2026 collision risks because they explicitly address fragmented knowledge and selective aggregation, though in memory/adapter rather than fixed-document action space.
5. V17 is methodologically distinct only if federation measurably creates composition-only opportunity and a federated action scorer realizes it. Phase-A failure ends the method claim.
